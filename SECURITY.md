# Security policy

HoxPi talks to a heating system. Please report vulnerabilities **privately**:
repository **Security** tab → **Report a vulnerability** (GitHub private vulnerability reporting).
Do not open a public issue for security problems.

You will get an acknowledgement within a few days; fixes are coordinated with you before anything is disclosed.

Scope: everything in this repository (bridge, dashboard, MCP server, MQTT/exporter, ESP32 firmware, install scripts).
HoxPi is meant for a trusted home network; see *Security notes* in the README for the hardening options
(2FA on the dashboard, MCP `allowed_clients` / `write_clients` / `token`).

---
